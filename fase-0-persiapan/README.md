# Fase 0: Persiapan

Perkiraan waktu: minggu 1-2

## Yang dipelajari
- [ ] Terminal dasar: `cd`, `ls`, `mkdir`, `cp`, `mv`, `rm`
- [ ] Git: `init`, `add`, `commit`, `push`, `pull`, `branch`, `merge`
- [ ] VS Code dan ekstensi dasarnya
- [ ] Instalasi Node.js (versi LTS)

## Latihan (satu folder per latihan)
- `latihan-terminal/` : catatan perintah terminal yang sudah dicoba
- `latihan-git/` : repo kecil untuk berlatih branch dan merge

## Target selesai
- [ ] Punya akun GitHub dan repository ini sudah di-push
- [ ] Nyaman membuat branch lalu merge
