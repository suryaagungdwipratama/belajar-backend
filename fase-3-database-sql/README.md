# Fase 3: Database dan SQL

Perkiraan waktu: minggu 13-18

## Yang dipelajari
- [ ] Konsep database relasional, primary key, foreign key
- [ ] `SELECT`, `INSERT`, `UPDATE`, `DELETE`, `WHERE`, `ORDER BY`, `LIMIT`
- [ ] `JOIN`, `GROUP BY`, `HAVING`, agregasi
- [ ] Relasi one-to-one, one-to-many, many-to-many
- [ ] Normalisasi dasar
- [ ] Index
- [ ] Transaction dan ACID
- [ ] Migrasi database

Database yang dipakai: PostgreSQL (atau MySQL).

## Latihan (satu folder per latihan)
- `perpustakaan-db/` : minimal 4 tabel berelasi, skema, data contoh, dan query
- `latihan-query/` : kumpulan soal SQL dari SQLBolt / PGExercises
- `erd/` : gambar ERD

## Target selesai
- [ ] Menulis query dengan beberapa `JOIN` tanpa contekan
- [ ] Bisa menggambar ERD sederhana
